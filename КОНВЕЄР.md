# Конвеєр «Наше слово» — задум і черга побудови

Погоджено оператором 25.09.2026 (схема — так; комп'ютер уночі — так; GitHub — так).
Файл веде головна; будує відділ інструментів, по фазах, кожна — зі звітом і пробою.

## Принцип

**Конвеєр — це скрипти, не сесії Claude.** Верстати вже є (`ns-scan`, `ns-prep`,
`ns-render`, `ns-build`, `ns-qc`); бракує стрічки між ними. Звичайний номер іде
від клавіші Q до готового PDF без Claude, і оператор бачить його один раз — на
огляді. Claude — технолог: налагоджує верстати, розбирає брак і «Поправити».
Усе, що не стандартне, лінію не зупиняє, а йде в чергу «на огляд».

## Станції і стан номера

Стан номера пишеться в **маніфест** (джерело істини), реєстр `issues.csv`
лише віддзеркалює його (`Sync-NsRegistry`).

|---|---|---|---|---|
| 1 | Скан | оператор, меню | як зараз | `scanned` |
| 1a | Приймання | скрипт одразу після Q | кількість сторінок проти звичної для року, кадри, дублі проти всіх сторінок, порожні, розмір; на моніторі — смуга підвалів усіх сторінок; Enter — прийнято, або номер сторінки — перезняти | `accepted` |

| 3 | Огляд | оператор, пункт меню «Огляд» | черга: відкриває PDF без OCR і список позначених сторінок; **A** — прийняти, **N** — нотатка «поправити» (текстом) | `ready` / `fix` |

**Стан на 25.09.2026:** стани `scanning` → `scanned` → `accepted` уже пишуться
(`state`, `state_log` у маніфесті; колонка `state` у реєстрі — фаза 2, коміт
`cd6a2e4`). `ready`, `review`, `fix`, `done`, `backed_up` — ще ні (фази 3-4).
«Завершити день» (станція 5 без позначки `backed_up`) — фаза 1, коміт `b012b5e`.

**Позначки, що ведуть на огляд:** сторона `Review` у `Get-NsEdgeLocal`, дірка
біля друку, OSD невпевнений, `insert_pages`, кількість сторінок не звична,
позначка «новий дизайн/календар» під час скану, рік без паспорта, будь-яке
зауваження QC. Перелік розширюється, не звужується.

**Паспорт року** (`NS_MASTERS\_catalog\years\<рік>.json`): правило корінця,
звична кількість сторінок, дизайн, вкладки. Складають інструменти на ПЕРШОМУ
номері року (замір зшивання — `ns-spinescan`). Рік без паспорта — усі номери
на огляд.

## Збереження роботи

Незамінне: **майстри + маніфести** (`NS_MASTERS`) і **скрипти з записами**
(`Scans`). PDF і `NS_WORK` відтворюються зі скриптів і маніфестів.

- **Щодня — «Завершити день»** (пункт меню): `git commit` теки `Scans` +
  `git push` на GitHub; `ns-backup` лише зміненого на зовнішній диск + звірка
  SHA-256 кожної нової сторінки; рядок у журнал.
- **Щотижня** — другий диск, який зберігається в іншому місці (3-2-1).
- Git для `Scans` заведено 25.09.2026 (`.gitignore`: без `*.before-*`,
  зображень і PDF). Копії `.before-*` перед зміною скрипту більше не обов'язкові —
  git зберігає кожну версію; інструменти комітять кожну закінчену зміну.

## Фази побудови (інструменти)

1. **«Завершити день»**: git commit/push + `ns-backup` (коли буде диск) — пункт меню.
2. **Приймання після Q** (станція 1a) + поле стану в маніфесті.
3. **Меню «Конвеєр»** (скільки номерів у якому стані) і **«Огляд»** (станції 3/3a).
4. **Нічна зміна**: `ns-conveyor.ps1 -Night` (обробка + збирання за станом);
   запуск через Планувальник завдань — створювати лише з дозволу оператора.
5. **Паспорт року** — на першому номері 2003.

Кожна фаза пробується на справжніх номерах (2003 р. і хвости 2002) до того,
як стати звичною; звіт числами.
